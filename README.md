#  Car Sales Dashboard (Power BI)

##  Overview
This project is an interactive Power BI dashboard created using a Car Sales dataset. 
It provides insights into sales performance through KPIs, charts, and filters.

##  Features
- Total Selling Price
- Total Cars
- Average Selling Price
- Average Odometer
- Sales by Make
- Sales by State
- Sales Trend
- Cars by Color
- Interactive Slicer

##  Tools Used
- Microsoft Power BI
- Kaggle Car Sales Dataset

##  Key Insights
- Analyzes car sales performance.
- Identifies sales trends by year.
- Compares sales across different states and car makes.
- Interactive filters for better analysis.
